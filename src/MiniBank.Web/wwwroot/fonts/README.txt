Place Persian font files here to be embedded by QuestPDF at runtime.

Recommended (download from official source):
- Vazirmatn-Regular.ttf
- Vazirmatn-Bold.ttf

Optional fallbacks:
- IRANSansX-Regular.ttf
- IRANSansX-Bold.ttf

Notes:
- File names must match exactly as listed above (or update ReportService.EnsureFontsRegistered accordingly).
- After copying fonts, no app restart is typically required, but recycling the app ensures registration on first report generation.
